# Switzer Webfonts

Self-hosted Switzer variable fonts from Fontshare (Indian Type Foundry).

## Files

- `Switzer-Variable.woff2` — Variable font (weight 100–900)
- `Switzer-VariableItalic.woff2` — Variable font italic (weight 100–900)
- Individual weights (Static fonts as fallback)
  - Switzer-Thin.woff2 (100)
  - Switzer-Light.woff2 (300)
  - Switzer-Regular.woff2 (400)
  - Switzer-Medium.woff2 (500)
  - Switzer-Semibold.woff2 (600)
  - Switzer-Bold.woff2 (700)
  - Switzer-Extrabold.woff2 (800)
  - Switzer-Black.woff2 (900)

## Configuration

Configured in `src/styles/global.css` with variable fonts for optimal performance and flexibility.
